## Overview

wb- 设计系统的目标是**安静**:暖米色画布(#f3f1ea)上,卡片用更浅的米白(#fcfbf7)加 1px 细线浮起;文字用松墨色(#22301f)而非纯黑;蓝色(#4f6ef0)只做强调——链接、选中态、主按钮,从不作为大面积底色。信息密度适中,层级靠三档墨色(#22301f/#6f7a6b/#9aa294)与衬线序号共同承担。

## Colors

### 表面
- **bg**(#f3f1ea):页面底色,暖米色
- **card**(#fcfbf7):卡片与输入框,比 bg 浅一档
- **line**(#e6e2d5):全部 1px 细线——卡片边、表格行、分隔

### 文字
- **ink**(#22301f):标题与正文,松墨绿黑
- **ink-2**(#6f7a6b):次要文字、说明、占位
- **ink-3**(#9aa294):最弱文字——页脚、禁用态

### 语义
- **accent**(#4f6ef0):唯一彩色强调——链接、选中态、主按钮、焦点边框
- **ok / warn / err**(#2e7d4f / #b7790a / #c0392b):状态语义,只用于状态点与语义徽章

### 强调使用纪律
accent 是**信号色不是底色**——按下的按钮、当前页签、选中行才允许填充;大面积使用会毁掉整个系统的安静感。

## Typography

| Token | 值 | 用途 |
|---|---|---|
| 标题 | 19px / 650 | 页面标题(wb-title) |
| 分区序号 | Georgia 衬线 / 17px / #b7790a | wb-sec-no——全系统唯一的衬线与暖金色,分区锚点 |
| 正文 | 13px / 1.55 | 默认;工作台是小字号高密度形态 |
| 大数字 | Georgia 衬线 / 24px / 600(wb-num) | KPI 值——数字用衬线是这套设计的签名 |

## Spacing

基础 4px;页面 padding 28px;卡片内 16-18px;区块间距 22px。**节奏靠组件 padding,不靠全局 gap**。

## Components

- **wb-card**:米白底 + 1px line + 14px 圆角,无阴影——分隔靠细线不靠投影
- **wb-btn.primary**:ink 底反白(bg 色反转),hover 降透明度;**wb-btn.ghost**:1px line 边框;disabled 降透明度
- **wb-chip.on**:1px ink 边框加粗为选中态——选中用"变重"表达,不用变色
- **wb-table**:行 hover 用 2.5% 黑色叠加,极轻
- **wb-sec**:衬线序号(暖金)+ 标题,是每个分区的开场

## Do / Don't

### Do
- 全部颜色走 theme.ts tokens,组件里不写裸 hex
- 分区用 wb-sec 衬线序号开场——这是这套设计的签名
- 数字(KPI/价格/统计)一律 wb-num 衬线
- 状态只用 wb-dot 与 wb-pill 的语义色表达

### Don't
- 不要引入第二强调色(红/紫/橙都与系统冲突;语义色除外)
- 不要用阴影做层级——这套系统全部靠细线与表面色差
- 不要把 accent 用作大面积底色
- 不要放大字号来强调——用字重与颜色层次

## Known Gaps

- 暗色主题未成体系(wb- 是浅色单主题);需要暗色时参考 DESIGN-terminal.md 的反转纪律
- 图标走官方 sprite(currentColor),颜色随文字——无独立 token
