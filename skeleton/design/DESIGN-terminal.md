## Overview

把工作台想象成一台**专业终端**:深炭底(#0d1117 系),一切都为可读性与密度服务。强调色是终端绿(#3fb950 系)——只做状态与焦点;数值与代码一律等宽字体;分区靠亮度阶梯(#0d1117 → #161b22 → #21262d)而非颜色。这套语言和 GitHub Dark 同源,开发者一眼就熟悉。

## Colors

### 表面(亮度阶梯)
- **bg**(#0d1117):页面底,最深一档
- **card**(#161b22):卡片/面板,亮一档
- **card-2**(#21262d):悬浮层/输入框,再亮一档
- **line**(#30363d):全部 1px 边框

### 文字(亮度阶梯)
- **ink**(#e6edf3):标题与正文
- **ink-2**(#8b949e):次要文字
- **ink-3**(#6e7681):最弱文字

### 语义
- **accent**(#3fb950):终端绿——焦点、成功、主按钮
- **warn**(#d29922):琥珀——警告与修改标记
- **err**(#f85149):红——错误与删除
- **info**(#58a6ff):蓝——链接与信息

### 纪律
彩色只做**状态与语法**(状态点、diff 标记、关键字),不做大面积底色。亮度阶梯是唯一的层级手段。

## Typography

| Token | 值 | 用途 |
|---|---|---|
| 标题 | 16px / 600 / #e6edf3 | 页面标题——终端风字号整体偏小 |
| 正文 | 13px / 1.6 | 默认 |
| **数值/代码** | ui-monospace, SFMono-Regular, Menlo / 12.5px | ★ 签名——所有数字、ID、路径、代码一律等宽 |
| 分区序号 | 等宽 / 15px / #3fb950 | 替代衬线序号——终端风不用衬线 |

## Components

- **wb-card**:card 底 + 1px line + 8px 圆角(终端风圆角整体收紧:8px,不用 14px)
- **wb-btn.primary**:accent 底深色字;ghost:1px line;hover 提亮边框
- **wb-table**:行 hover 用 card-2 提亮;等宽字体用于所有数值列
- **wb-sec**:序号改等宽绿色(如 `01`),不用衬线

## Do / Don't

### Do
- 数值/ID/路径/代码一律等宽
- 三档亮度阶梯是唯一层级手段;彩色只做语义
- 状态点、diff 标记、行号用语义色
- 圆角 8px(终端风收紧,不用 14px)

### Don't
- 不要在暗底上用纯黑文字或纯白文字(对比过强)
- 不要引入彩色大面积底色;不要渐变
- 不要用衬线(与终端语言冲突)
- 不要低于 12px 的字号(暗底小字可读性差)
