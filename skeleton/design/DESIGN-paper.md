## Overview

把工作台想象成**一张纸**:暖纸底(#faf7f2),墨色文字(#2b2b26),正文用宋体系衬线,行距宽(2.0),栏宽收窄(每行 32-38 字)。界面装饰降到最低——没有卡片边框、没有彩色按钮,层级全靠留白与字重。按钮是纸上的一枚墨章:细边框、墨色文字、按下变实。

## Colors

### 表面
- **bg**(#faf7f2):页面底,暖纸色
- **card**(#fffdf8):更亮的纸面(编辑区/引文底)
- **line**(#e8e2d6):唯一线色,1px

### 文字
- **ink**(#2b2b26):正文与标题,墨黑偏暖
- **ink-2**(#6b6a5f):次要文字与批注
- **ink-3**(#a09e8f):页码、最弱装饰

### 语义
- **accent**(#8a6d3b):墨棕——标题旁的小标记、当前章节指示、链接下划线
- **err**(#a13c3c):错误,墨红

### 纪律
整套系统只有墨、纸、棕三个色相。强调 = 墨棕的小面积点缀(下划线、侧边标记),从不用填充色块。

## Typography

| Token | 值 | 用途 |
|---|---|---|
| 正文 | Georgia, Songti SC, serif / 15px / 行高 2.0 | ★ 阅读正文——衬线 + 宽行距是这套系统的签名 |
| 标题 | 20px / 600 / sans(黑体) | 页面标题用黑体,与衬线正文形成对比 |
| 章节标记 | accent 墨棕 / 12px / letter-spacing 0.1em | 章节旁的小写标记(如 `§ 2`) |
| 引文 | 衬线 / ink-2 / 左边框 2px accent | 引文块 |

## Spacing

- 栏宽:**每行 32-38 字**(约 620-680px)——阅读栏宽是第一纪律,宁可留白也不超宽
- 行距 2.0;段落间距 1.2em;章节间距 3em
- 页面留白:左右各 max(8%, 64px)——纸的边缘

## Components

- **wb-card**:无边框无底色——分区靠留白与细线
- **wb-btn**:1px 墨边 + 墨字,hover 变实底墨字反白;主按钮 = 实底墨底纸字
- **wb-table**:罕见;若有,行距放宽、无 hover 底色
- **wb-sec**:不用序号——章节靠 `§` 标记与留白

## Do / Don't

### Do
- 正文一律衬线 + 宽行距;界面元素(按钮/标签)用黑体对比
- 强调用墨棕小点缀(下划线/侧标),不用色块
- 留白是设计的一部分——空就是内容

### Don't
- 不要放 KPI 大数字网格、彩色徽章、图标阵列(与纸感冲突;那些是工作台的事)
- 不要用纯白(#fff)底——暖纸色才有"纸"的质地
- 不要加阴影和圆角卡片——纸是平的
